Pictures of a scene: quiet music at 8 s and 16 s, loud music at 21 s. Overlays and transitions are shown over one 2D and one 3D reference scene. The rating is the author's own estimate of how much there is to see (1 to 9); the genre list says which presets play the entry. In the detail view the arrow keys page through the selection, and the address in the browser is a link to the entry. Project on GitHub
